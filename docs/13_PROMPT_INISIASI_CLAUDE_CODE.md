## Catatan untuk Anda (di luar prompt)

- **Mengapa `.git/info/exclude`, bukan `.gitignore`?** `.gitignore` ikut ter-push; aturan di dalamnya (`/CLAUDE.md`, `/.claude/`) akan terlihat di GitHub. `.git/info/exclude` hanya ada di mesin Anda.
- **Konsekuensi:** rekan tim tidak mendapat `docs/` dan `CLAUDE.md` lewat git. Bagikan `rebottle-docs.zip` sendiri-sendiri, dan taruh di `docs/` dengan cara yang sama. Papan tugas `docs/BOARD.md` juga ikut lokal; bila ingin papan bersama, pakai Notion/Trello atau pindahkan hanya berkas itu ke repo (dan beri tahu agen).
- **Clone baru atau mesin lain:** aturan `.git/info/exclude` tidak ikut. Ulangi langkah itu (atau jalankan prompt lagi) sebelum menaruh `docs/` agar tidak tak sengaja ter-commit.
- Bila repo sudah punya commit lama yang mengandung atribusi, riwayat lama tidak diubah (tanpa force push); beri tahu agar kita tangani terpisah.
- Pemeriksaan jejak AI di berkas (butir 5) mengecualikan `package-lock.json`. Bila ada paket pihak ketiga yang kebetulan bernama mengandung kata itu, laporkan, jangan hapus.
